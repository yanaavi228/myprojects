# 🗄️ SQL Тренажёр

Современный интерактивный тренажёр SQL прямо в браузере. Учебная база — магазин компьютерной техники. Без сервера, без базы данных, без установки — всё работает на клиенте.

## Возможности

- **📖 Основы SQL** — 8 коротких уроков: от первого `SELECT` до связей таблиц и `JOIN`. Примеры можно менять и запускать прямо на странице
- **Практика** — 17 задач трёх уровней (лёгкий / средний / сложный). Под заданием всегда показана ожидаемая таблица, а кнопка «Выполнить» сравнивает с ней ваш результат
- **Проверка по результату**, а не по тексту запроса — любой правильный вариант засчитывается
- **Черновики по каждой задаче** — введённый запрос и результат проверки сохраняются при переключении между задачами и после перезагрузки страницы; список задач можно сворачивать
- **🧪 Песочница** — доступна после входа в аккаунт: можно делать со своей копией базы что угодно (любые запросы: `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `DROP`, `ALTER` и т.д.); изменения сохраняются
- **✨ ИИ-конструктор заданий** — опишите, что хотите потренировать, и ИИ составит задачу. Уровни строго ограничены: лёгкий — одна таблица без JOIN, средний — один JOIN или одна группировка, сложный — всё остальное. Каждое задание проверяется автоматически. Запросы не по теме сайта отклоняются, а опечатки и орфографические ошибки в словах не мешают. Сгенерированные задания сохраняются в браузере
- **Материалы** — подборка открытых источников с подробным обзором каждого: нажмите на карточку и прочитайте, что внутри, плюсы и минусы, кому подходит и как заниматься
- **Прогресс** сохраняется в браузере, светлая/тёмная тема, адаптивный дизайн для телефона

## Быстрый старт

**Как скачать:** на странице репозитория нажмите зелёную кнопку **Code → Download ZIP**, распакуйте архив — весь код открыт, можно смотреть и изменять любой файл.

Далее выберите любой способ запуска:

**Способ 1 — просто открыть файл**
Откройте `index.html` в любом браузере (двойной клик или `start.bat`). Всё работает офлайн.

**Способ 2 — локальный сервер (Windows)**
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Затем откройте http://localhost:8585

## Доступ для других

Ваш компьютер может быть сервером для других посетителей:

- **По локальной сети** — сервер слушает все интерфейсы: запустите `server.ps1` и отправьте ссылку, которую он выводит строкой `LAN: http://...:8585`
- **Автозапуск и брандмауэр** — один раз запустите `setup-hosting.ps1` от имени администратора: откроет порт 8585 в брандмауэре и настроит старт сервера при входе в Windows
- **Из интернета** — запустите `share-public.ps1`: поднимет бесплатный туннель Cloudflare и покажет публичную https-ссылку (сайт доступен, пока включён компьютер)

Сервер многопоточный — несколько посетителей могут работать одновременно. Аккаунты и песочницы хранятся на сервере (`users.json`, `sb-*.json` рядом с server.ps1), поэтому каждый посетитель входит в свой аккаунт с любого компьютера.

## ИИ-конструктор

Конструктор работает из коробки через бесплатный онлайн-ИИ, а при его недоступности — через локальный генератор по шаблонам. Для максимального качества заданий укажите свой бесплатный ключ в настройках (⚙️ в правом нижнем углу страницы — кнопка видна только администратору, аккаунт `admin`):

- **Google Gemini** — aistudio.google.com/apikey
- **Groq / Llama** — console.groq.com/keys
- Любой OpenAI-совместимый API

Ключ хранится только в вашем браузере (localStorage) и отправляется лишь в API выбранного провайдера.

Чтобы встроить ключ для всех посетителей своей копии сайта, впишите его в `BUILTIN_KEY` в начале скрипта в `index.html`.

## Аккаунты

При работе через `server.ps1` аккаунты **общие**: логин и PBKDF2-хэш пароля хранятся в `users.json` на сервере, личная копия базы песочницы — в `sb-<логин>.json`. Войти в свой аккаунт можно с любого компьютера сети. Если открыть `index.html` без сервера, аккаунты остаются локальными (в `localStorage` браузера).

Это учебная защита, а не настоящая безопасность: трафик в локальной сети не шифруется, а файлы с хэшами может прочитать тот, у кого есть доступ к компьютеру-серверу. Не используйте реальные пароли.

## Учебная база

| Таблица | Столбцы |
|---|---|
| `categories` | id, name |
| `products` | id, name, category_id, brand, price, stock |
| `orders` | id, product_id, customer, qty, status, order_date |
| `reviews` | id, product_id, author, rating, review_date |

Статусы заказов: `paid`, `new`, `cancelled`. Оценки в отзывах: от 1 до 5.
Практика, уроки и проверка заданий всегда работают на неизменной исходной базе, а изменения делаются только в песочнице.

## Технологии

- Один HTML-файл, ванильный JS — без сборки
- [AlaSQL](https://github.com/AlaSQL/alasql) — SQL-движок в браузере (включён локально, работает офлайн)
- В практике разрешены только `SELECT` (изменения — в песочнице); оконные функции и CTE не поддерживаются (ограничение AlaSQL)
